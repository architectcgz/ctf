# Feedback Recording Notes

This repository records agent-discovered improvement items under `feedback/`, not `docs/improvements/`.

Use a dated filename:

```text
feedback/YYYY-MM-DD-short-topic.md
```

Each entry should follow the local feedback contract:

- `## 问题描述`
- `## 原因分析`
- `## 解决方案`
- `## 收获`
- `## 沉淀状态`

`## 沉淀状态` must include the current status plus owner and links so the lesson can be traced back to the rule, skill, script, or document that absorbed it.
