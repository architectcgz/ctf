## 原始需求

网络攻防靶场是实现网络安全技术研究、校赛网络安全人才选拔的重要平台。通过综合云管理平台，对教学实验、综合实战、仿真实战、攻防对抗等功能进行集中监控与管理。使用 Docker 技术，快速生成靶机，为我校信息安全类专业开展网络安全竞赛提供训练比赛环境。

核心功能分四模块：

1. 靶场管理：管理员可配置多样化漏洞环境，如 SQL 注入、XSS、权限绕过，支持自定义拓扑与难度分级。
2. 攻防演练：学员选择靶场后获取攻击目标，系统自动记录攻击步骤与漏洞利用过程，实时反馈得分。
3. 竞赛管理：支持团队对抗模式，自动监控攻击流量、统计防守成功次数，生成实时排行榜。
4. 技能评估：基于实训数据生成能力画像，推荐针对性靶场练习，导出实训报告供教学复盘。

## 主线目标

平台的核心目标是：基于 Docker 快速提供可管理、可复用、可评分、可复盘的网络攻防训练与竞赛环境，服务于日常教学、实战训练和校赛选拔。

围绕这条主线，后续需求判断默认以以下四类能力是否闭环为准：

| 模块 | 主目标 | 关键关键词 |
|------|--------|------------|
| 靶场管理 | 能创建、配置、发布和复用漏洞环境 | 漏洞环境、拓扑、难度、资源、Flag |
| 攻防演练 | 能启动靶机、完成训练、记录过程并实时计分 | 实例、过程记录、漏洞利用、得分反馈 |
| 竞赛管理 | 能支撑团队化竞赛与攻防对抗并形成排行榜 | 团队对抗、攻击流量、防守统计、排行榜 |
| 技能评估 | 能基于训练数据形成画像、推荐和教学复盘 | 能力画像、推荐练习、报告、复盘 |

## 模块拆解

### 1. 靶场管理

- 管理员可配置多样化漏洞环境。
- 漏洞类型至少覆盖用户明确提出的 SQL 注入、XSS、权限绕过，并允许继续扩展。
- 支持自定义网络拓扑。
- 支持难度分级，便于教学和竞赛分层使用。

### 2. 攻防演练

- 学员可以选择靶场并获取攻击目标。
- 系统需要自动记录攻击步骤与漏洞利用过程。
- 系统需要对训练结果进行实时得分反馈。

### 3. 竞赛管理

- 支持团队对抗模式。
- 自动监控攻击流量。
- 自动统计防守成功次数。
- 生成实时排行榜。

### 4. 技能评估

- 基于实训数据生成能力画像。
- 根据画像推荐针对性靶场练习。
- 支持导出实训报告。
- 报告服务于教师教学复盘。

## 范围校验口径

后续任何迭代，如无法直接对应到以下问题之一，原则上应视为可能偏离主线，需要重新确认：

- 这项改动是否直接增强了靶场管理能力？
- 这项改动是否直接增强了攻防演练过程或得分反馈？
- 这项改动是否直接增强了竞赛组织、攻防统计或排行能力？
- 这项改动是否直接增强了能力画像、训练推荐或教学复盘能力？

## 当前执行约束

- 后续“继续”类开发默认应优先落在上述四个模块内。
- 若出现多个未完成项，优先补齐已经开始建设但尚未闭环的模块能力。
- 教师侧教学复盘相关工作，属于“技能评估”模块，不属于偏题支线。
